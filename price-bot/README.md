# AVIOR Shop — Telegram-бот с прайсом

Бот показывает клиентам каталог техники с ценами поставщика + ваша наценка.
Цены обновляются пересылкой поста с прайсом из группы поставщика боту
(позже подключим автоматический сборщик).

## Что умеет

**Клиентам:** категории → разделы → список позиций с ценами; кнопки ➕ добавляют товар
в корзину; оформление заказа (способ доставки + телефон); вопрос менеджеру; контакты.
Если поставщик поменял цену, корзина сразу показывает новую, а пропавший товар помечает «закончился».

**Заказы** приходят владельцу в личку: товары, цены продажи и закупки, наценка, клиент
(ссылка на аккаунт, @username, телефон) и способ доставки. Кнопки ✅ Подтвердить / ❌ Отменить
уведомляют клиента. `/orders` — последние заказы.

**Наценка по умолчанию:** +10 000 ₽ на всё (телефоны, ноутбуки, Mac, планшеты), +5 000 ₽ на категории
аксессуаров (AirPods, наушники, очки, часы, колонки — по словам в названии категории, `ACCESSORY_WORDS`).
Чехлы, зарядки, кабели, стёкла и доп. гарантия в бот не попадают (`/exclude` — список слов).

**Владельцу** (`/admin` — полная справка):
- переслать боту пост с прайсом → бот разберёт цены, спросит категорию (один раз),
  обновит каталог и пришлёт отчёт: что подорожало/подешевело, что появилось/пропало;
- отправить боту файл экспорта группы `result.json` → обновятся все категории сразу;
- `/excel` — текущий прайс с вашими ценами в Excel;
- `/markup 10` или `/markup 10 500` — общая наценка (+10%, +500 ₽);
- `/round 100` — округление цен вверх до 100 ₽;
- `/catmarkup 3 15` — своя наценка для отдельной категории;
- `/cats`, `/newcat`, `/rename`, `/move`, `/delcat` — управление категориями;
- `/stats` — сколько людей заходило (новые и активные за день/неделю/месяц), заказы и выручка,
  популярные категории, последние посетители. Заходы владельца не считаются.

## Б/у устройства (трейд-ин)

Раздел «♻️ Б/у (проверено)» — кнопка в общем каталоге. Цена — та, что вы указали, без наценки.

- Добавить: /bu → «➕ Добавить б/у устройство». Бот спросит по шагам: модель → % аккумулятора →
  внешнее состояние → комплект/комментарий → цена (можно `45000/38000` — цена и закупка) → фото (до 10, можно альбомом).
  После «✅ Готово» бот ставит на фото логотип и адрес avior.moscow и показывает карточку целиком, как её увидит клиент.
  Любое поле можно исправить кнопками ✏️; на витрину устройство попадает только после «✅ Опубликовать».
- Раздел (смартфоны, ноутбуки, планшеты, часы…) определяется по модели, его можно поменять кнопками в карточке перед публикацией.
- /bu — список всех устройств; «✅ Продано» убирает устройство с витрины. В карточке устройства — «💰 Изменить цену».
- Устройство в одном экземпляре: после оформления заказа оно пропадает с витрины; заказ отменён — возвращается,
  подтверждён — считается проданным.
- Текст про проверку в разделе меняется в `.env`: `USED_NOTE=...`

## Для клиентов

- **Стартовый экран**: «🛍 Каталог устройств», «🔧 Ремонт», «💰 Трейд-ин», вопрос, контакты. Поиск, категории
  и «♻️ Б/у» — внутри каталога.
- **Поиск**: клиент просто пишет модель («15 про 256», «macbook air m3») — бот находит товары во всех
  категориях и в б/у, ➕ кладёт в корзину. Понимает русское написание (айфон, про, гб, макбук…).
- **Трейд-ин**: «💰 Сдать устройство в трейд-ин» — модель, АКБ, состояние, фото, телефон. Заявка приходит
  владельцу с кнопками «💬 Предложить цену» / «❌ Не принимаем»; клиент отвечает «Согласен» / «Не подходит».
- **Ремонт**: запись (устройство, проблема, телефон) уходит в CRM — туда же, куда заявки с сайта
  (`CRM_LEAD_SECRET` в `.env` — тот же секрет, что `crm_lead_secret` в `config.php` сайта), и владельцу в Telegram.
  Статус клиент смотрит по номеру заказа и телефону — из CRM, как на сайте; бот раз в 20 минут проверяет статус
  и пишет клиенту, когда он изменился. Для заказов вне CRM: `/repair 1234` → кнопки статусов.
- **Напоминания о профилактике**: когда ремонт выдан (статус «выдан» из CRM или «📦 Выдано» в `/repair`) у клиента,
  который следил за статусом в боте, владелец получает вопрос «Напомнить о профилактике?» → 3 / 6 / 12 мес / не нужно.
  В срок бот сам пишет клиенту (днём, 11–20 по Москве) и предлагает записаться. `/remind` — список и отмена.
- **Услуги к покупке**: если в корзине телефон, планшет или ноутбук, при оформлении бот предлагает отметить
  наклейку стекла, перенос данных, настройку (список — `SERVICES=` в `.env`). Цена услуг — по согласованию.
- **Уведомления о ценах**: после каждого обновления прайса клиенты получают сообщение, если товар из их корзины
  подешевел или снова появился. Отключается кнопкой «🔕».
- **Ответ клиенту из бота**: под вопросом, записью на ремонт и заявкой на трейд-ин — «✍️ Ответить клиенту».
  Ответ (текст или фото) клиент получает от бота AVIOR Shop; его ответ снова придёт владельцу.
- **Откуда приходят клиенты**: `/links` — ссылки на бота с метками (сайт, Авито, QR на стойке, квитанция,
  визитка, карты) и QR-коды для печати; `/links ozon` — своя метка (Instagram, WhatsApp, MAX и ВКонтакте уже есть в списке). Метка запоминается при первом заходе,
  `LINK_USERNAME=avior_app` в `.env` — /links покажет короткие ссылки (QR-коды остаются на основном адресе);
  в `/stats` — раздел «Откуда пришли» (люди и заказы), в списке пользователей — источник у каждого.
- **Анимированные значки** в тексте и на кнопках по всему Telegram-боту: `/emoji` — прислать пары
  «обычный значок, сразу за ним анимированный из премиум-набора» (🏠🏠 📞📞 …), можно в несколько заходов.
  Подмена делается при отправке любого сообщения (`app/emoji.py`). Нужен Telegram Premium у владельца бота;
  если Telegram значок не принял — сообщение уходит с обычными. `/emoji off` — убрать все замены.
- **Рассылка**: `/send` — сообщение (текст или фото) всем, кто заходил в бота, с превью перед отправкой
  и кнопкой «🔕 Не присылать новости».
- **Канал для б/у**: добавьте бота администратором канала и напишите `/channel @канал`. Новые б/у
  публикуются туда с кнопкой «🛒 Купить в боте» (открывает карточку), проданные помечаются «ПРОДАНО».
  `/channel all` — опубликовать то, что уже на витрине.

## Бот в MAX

Тот же бот для клиентов в мессенджере MAX — отдельная служба `avior-max` рядом с Telegram-ботом,
с общей базой: каталог, цены, б/у, корзина, заказы и статистика одни на оба мессенджера.

- Для клиентов в MAX: каталог, поиск, корзина и заказ (телефон — кнопкой «Отправить мой номер»), б/у с фото,
  ремонт (запись в CRM, статус из CRM), трейд-ин с фото, вопрос мастеру. Ссылки с метками: `max.ru/<бот>?start=vk`.
- Управление — по-прежнему в Telegram: заказы и заявки из MAX приходят владельцу с пометкой «MAX»;
  ответ клиенту, статус заказа, оценка трейд-ина, статус ремонта, снижение цен и рассылка сами уходят в MAX.
- Клиенты MAX хранятся в базе с отрицательными id; в /stats — сколько людей из Telegram и из MAX.

Подключение:
1. Создайте бота на business.max.ru, токен — в `.env`: `MAX_TOKEN=…`
2. `sudo -u avior-bot .venv/bin/python manage.py max-check` — проверка связи и токена.
3. `cp avior-max.service /etc/systemd/system/ && systemctl daemon-reload && systemctl enable --now avior-max`

## Бот в WhatsApp (упрощённый)

Служба `avior-wa` с той же общей базой, через официальный WhatsApp Cloud API (Meta). Меню — списком,
каталог — через поиск по модели (WhatsApp позволяет до 3 кнопок или список до 10 пунктов), б/у — карточкой с фото,
заказ (телефон — номер WhatsApp клиента), запись на ремонт в CRM и статус из CRM, трейд-ин с фото, вопрос мастеру.
Управление — в Telegram: всё из WhatsApp приходит владельцу с пометкой «WhatsApp», ответы уходят клиенту в WhatsApp.

Ограничение WhatsApp: написать клиенту первым можно только в течение 24 часов после его последнего сообщения
(дальше — только платными шаблонами Meta). Поэтому статус заказа или ремонта, отправленный позже, может не дойти —
владелец увидит «не доставлено» и позвонит.

Подключение:
1. Поддомен (например, `wa.avior.moscow`) → A-запись на IP сервера бота; HTTPS — Caddy (`Caddyfile.example`).
2. developers.facebook.com: приложение типа «Бизнес» → продукт WhatsApp → API Setup (WA_PHONE_ID, токен);
   Configuration → Webhook: `https://wa.avior.moscow/whatsapp`, Verify token = WA_VERIFY_TOKEN, подписка `messages`.
3. `.env`: WA_TOKEN, WA_PHONE_ID, WA_VERIFY_TOKEN, WA_APP_SECRET.
4. `cp avior-wa.service /etc/systemd/system/ && systemctl daemon-reload && systemctl enable --now avior-wa`

## Весь прайс одним файлом (экспорт группы)

1. В **Telegram Desktop** откройте группу поставщика → ⋮ → **Экспорт истории чата**.
   Снимите все галочки (фото, видео, файлы…), формат — **JSON**. Получится `result.json`.
2. Дальше любой из способов:
   - **отправить `result.json` боту** — он обновит все категории и пришлёт отчёт
     (если файл больше 20 МБ — сначала `python manage.py catalog result.json` и отправить `catalog.json`);
   - `python manage.py excel result.json` — Excel с вашими ценами, бот не трогается;
   - `python manage.py import result.json` — обновить цены в базе бота из терминала
     (в Docker: положить файл в `data/` и `docker compose run --rm bot python manage.py import data/result.json`).

Скрипт находит пост-меню с кнопками категорий, проходит по ссылкам и берёт актуальный текст каждого поста.

## Сборщик цен на Windows-сервере (автоматическое обновление)

Невидимый браузер Chromium на Windows-сервере читает канал поставщика через web.telegram.org
от имени обычного аккаунта (api_id не нужен) и по SSH отправляет прочитанное на Linux-сервер
бота (`manage.py import-collected`). Бот обновляет цены и присылает владельцу отчёт об
изменениях; если канал прочитан не полностью — цены не трогаются, приходит скриншот.
Токен бота на Windows не нужен. Меню поставщика бот запоминает, когда ему отправляют экспорт
канала (`result.json`) — это нужно сделать один раз и повторять, если у поставщика появились
новые кнопки (сборщик об этом предупредит).

```powershell
git clone -b claude/clever-turing-0k1k99 https://github.com/vahmedov-code/avior-site.git C:\avior
cd C:\avior\price-bot
py -m venv .venv
.venv\Scripts\pip install -r requirements-collector.txt
.venv\Scripts\python -m playwright install chromium
copy collector.env.example collector.env
.venv\Scripts\python collector_win.py login     # окно браузера: войти по QR-коду (один раз)
.venv\Scripts\python collector_win.py run --report
```

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`) со своего основного аккаунта,
   скопируйте токен.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`, `ADMIN_IDS`, контакты.

### На сервере как служба (без Docker)

```bash
git clone -b claude/clever-turing-0k1k99 https://github.com/vahmedov-code/avior-site.git /opt/avior
cd /opt/avior/price-bot && ./install.sh
nano .env                      # вписать BOT_TOKEN
systemctl restart avior-bot
journalctl -u avior-bot -f     # логи
```

Обновление кода: `cd /opt/avior && git pull && systemctl restart avior-bot`.
Импорт из терминала: `cd /opt/avior/price-bot && sudo -u avior-bot .venv/bin/python manage.py import result.json`.

### На сервере через Docker

```bash
cd price-bot
cp .env.example .env && nano .env
docker compose up -d --build
docker compose logs -f        # посмотреть, что бот запустился
```

### Без Docker

```bash
cd price-bot
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env && nano .env
python -m app.main
```

База (категории, цены, наценки) хранится в `data/shop.db` — её стоит бэкапить.
